Logo

The logo has two parts: the logotype and the bag-and-heart icon. They are used separately. The supplied SVGs are used untouched, with no recolouring, stretching or effects.

Graphic elements

Every element grows from the bag-and-heart symbol. The tube elements were rendered from the supplied guideline PDF at 5×, because their shaded gradients don't survive SVG export.

Oversized line logo

Used in hero, anchored bottom-right, bleeding off the right and bottom edges · File line-logo-dark.webp (Blackberry baked in) · Rule only on Blackberry, always bleeding off an edge

Continuous line motif

Used in footer and this page's header · Build .line-motif with --h (height) and --x (loop position); the slice fills both sides so the line runs edge to edge at any width · Rule extend with the slice, never stretch the loop image

Oversized solid logo

Used in How it works, anchored top-right behind the steps · File solid-logo-basil.webp (Basil baked in) · Rule only on Basil

Repeating pattern

Used in Become a partner band, behind a Blackberry panel · File pattern.svg, Kale glyphs at 38% opacity on a Basil ground · Build rebuilt from the supplied Pattern.svg as an SVG <pattern> (38.05 × 68.95 cell, rotated 10.33°) so it tiles without seams · Rule never put text directly on the pattern

Icons

UIcons by Flaticon, Bold Rounded set, matching Nunito's rounded strokes. Converted from the icon font into one SVG sprite (assets/icons/sprite.svg) so only the icons used are shipped. The sprite is inlined at the top of each page (by src/build.py) so icons work offline. Use with <svg class="icon"><use href="#i-NAME"/></svg>; they take currentColor. Credit "Uicons by Flaticon" is required (it's in the footer).

Buttons & links

Two button types, square-shouldered (12px radius) to echo the bag's corners. Minimum height 48px (40px for the small header size). Labels in Nunito 800.
